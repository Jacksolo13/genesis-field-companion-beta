# Genesis Galactic Field Companion

Free, unofficial v0.9 community beta for the Star Wars Genesis modlist for Starfield. This companion runs independently of the game and uses Genesis 8.8 as its baseline. The Sources tab distinguishes documented game information from fan roleplay material and items that still need verification.

In Chrome, open the site and use the install option. Visit once online to make the app available offline. Planner and journal data stay in your browser. Use Journal → Export backup before changing the browser, device or website address.

Game reference: [Star Wars Genesis](https://genesismodlist.com/), by DeityVengy and contributors. Aurebesh Rodian font by [AurekFonts](https://github.com/AurekFonts/Aurebesh_Rodian), distributed under the [MIT license](AUREBESH-LICENSE.txt).
